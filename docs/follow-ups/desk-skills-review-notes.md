# Where a permission prompt's details come from

`cc-desk prompt yes|no` needs a project, a record, and a follow-ups folder, and the brief gives the
desk none of them. The brief or the skill (`skills/cc-desk/SKILL.md`) should say where the desk
reads them. Pass 2 (desk-skills)'s whole-branch review raised this, and pass 3 (desk-open) left it
open.

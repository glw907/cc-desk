## `bin/.local/bin/pass-body-check`, a new script

One file of stdlib Python run as `python3 -I`, with tests under `tests/`.

```
pass-body-check <owner/repo> <pr> [--plan <path>]
```

It reads the body with `gh pr view` and exits 0 when the body is clean, 1 with one line per
failure, and 2 on a usage error or a failed read. It checks:

- the four lines, each in the form `round-run.md` "Evidence" gives;
- with `--plan`, an entry under `## Acceptance` for every item in the plan's acceptance list;
- a tag from `round.md` "Miss tags" at the start of every line under `## Planning misses`;
- a `pass-score` comment that parses as JSON and holds the six keys.

## `bin/.local/bin/round-watch`

The watch also exits 0 in two new cases, each printed as a line that names the session:

- A session of the round reads blocked or done, whatever the others are doing.
- Nothing in the record the watch builds (its session rows and pull request lines) has changed
  for 20 minutes. `ROUND_WATCH_STALE` sets the period in seconds for tests, default 1200. The
  watch reads no session's job file for this.
